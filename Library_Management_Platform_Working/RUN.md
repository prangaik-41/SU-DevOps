# How to Run

## Windows

1. Install Python 3.10+.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

5. Open http://127.0.0.1:5000
